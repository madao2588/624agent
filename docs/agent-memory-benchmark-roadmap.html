Agent Memory Leaderboard · Textual Track

从“按词找到”走向“真正记得”

这不是一个让 Agent 自己答题的项目，而是一套负责理解、组织和召回长期记忆证据的系统。平台统一回答和评分，我们要做的是把正确、完整、可审计的原始证据排在前面。

Current verdict V1 已经能被评测，但还不是有竞争力的应试版。

接口、幂等、隔离和原文证据已经可靠；下一步必须补齐语义、时间、关系、更新、偏好与规则记忆。

01 · 先看边界

系统负责记忆，平台负责回答

LLM 可以在内部帮助理解和检索，但 Search 的外部输出只能是记忆证据。这个边界决定了整个架构。

Evaluation Platform

固定回答模型、提示词、评分器和汇总规则。

ANS
统一回答根据我们返回的证据生成答案
EVAL
统一评分按数据集规则汇总最终结果
EVIDENCE只返回原始证据不能直接回答，也不能把生成答案伪装成记忆。
ISOLATIONuser_id 强隔离数据库、缓存、索引、图谱与回表路径都必须隔离。
ORDER排序就是决策平台按返回顺序最多读取 Top 100，前排噪声会直接伤害结果。
MODELLLM 锁定合规Add/Search 内的生成式模型使用 gpt-4o-mini；Embedding 架构不受限定。

04 · 核心难点

真正难的是“正确组织证据”

召回一条相似文本只是起点。应试系统必须在准确性、完整性、时间一致性、成本和可审计性之间取得平衡。

01漏召回

语义与精确匹配并存

向量擅长同义改写，BM25 擅长姓名、日期、编号；任何单一路径都会有盲区。

BM25 + Dense 独立召回，RRF 融合后再重排。
02证据不全

多跳不是单条相似文本

人物、事件和结果可能分散在多个非相邻会话，需要找到完整证据链。

实体关系图 + 有界一至二跳扩展 + 覆盖度重排。
03状态过期

时间、更新与矛盾

旧安排和新安排都是真实历史，但只有最新有效状态回答“现在是什么”。

事件时间线 + 事实版本 + 替代/撤销关系。
04过度推断

隐含偏好必须有来源

一次偶然选择不能直接变成稳定画像，偏好需要多次证据和反证修正。

偏好主题 + 支持次数 + 最近时间 + 正反来源。
05漏掉约束

规则和流程要完整

少一个前置条件、例外或步骤，最终任务就可能完全失败。

结构化条件、步骤、例外和输出要求，并按覆盖完整性排序。
06噪声污染

证据不足时允许为空

低相关结果填满 Top K 会诱导平台回答模型产生错误答案。

绝对相关性门槛 + 候选差距 + 空数组策略。
05 · 目标架构

LLM 理解，多路检索，原文作证

结构化记忆是索引，不是事实本身。所有路径最终必须落回带有 user_id、session_id 和 timestamp 的原始消息。

Add一次写入，多种视图

06 · 主要步骤

按依赖推进，不一次堆满功能

每一阶段都必须有可验证的完成证据。没有可复现增益的复杂机制，应当被简化或删除。

00

冻结可靠契约基线

锁住同步、幂等、隔离、原文回表、Docker 和黑盒预检。

验收证据增强关闭时与 V1 行为一致，原有测试全部通过。
01

模型与语义基础设施

接入 gpt-4o-mini、Embedding、超时重试、调用限制和脱敏观测。

验收证据结构化输出稳定，向量在 Add 成功前可搜索，密钥不泄漏。
02

结构化记忆写入

建立事实、实体、关系、事件、时间、偏好、规则和状态 schema。

验收证据每条辅助记忆都绑定原文来源，无来源内容不能入索引。
03

混合检索与重排

BM25 + Dense + RRF + 去重/多样性，再回表读取原始消息。

验收证据改写召回提升，姓名日期不退化，排序确定且可复现。
04

时间、状态、图与规则治理

处理多跳、更新、矛盾、隐含偏好、流程完整性和空结果。

验收证据新状态优先、多跳证据齐全、无答案不被噪声填充。
05

公开基准回归与消融

比较 lexical、dense、hybrid、graph、temporal 和 rerank。

验收证据新增机制有独立增益；检索、延迟、成本与失败类型可追踪。
06

提交冻结与复现

锁定依赖、模型、提示词、配置、Docker、版本和方法披露。

验收证据平台从干净环境可构建运行，提交版本与正式版本一致。
最近一轮只做什么先完成 gpt-4o-mini 适配、Embedding 持久化、Dense Retriever、BM25 + Dense RRF 和对应回归；确认语义检索获得可复现增益后，再进入知识图谱与时间治理。
07 · 成功护栏

应试不等于投机

真正可持续的冲榜策略，是把公开基准暴露的问题固化成通用能力，同时保持证据、隔离和复现边界。

SRC

原文优先

摘要、图谱和状态只帮助找证据，不能替代原始消息。

UID

全链路隔离

每张表、缓存、索引和图查询都显式包含 user_id。

LAB

禁止标签泄漏

答案、题型标签和 gold evidence 不能进入查询规划。

REP

结果可复现

锁定模型、提示词、版本和配置，并记录每个机制的消融。

最终目标：不是“它知道答案”，而是“它找对了记忆”。

当平台收到的是完整、低噪声、时间一致、来源清楚的原始证据，统一回答模型才有机会稳定答对。我们的竞争力最终体现在证据的召回、组织和排序上。
