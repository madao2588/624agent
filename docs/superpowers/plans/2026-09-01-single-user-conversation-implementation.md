# 单用户多轮记忆体验实现计划

## 验收标准

- 页面中不再出现身份切换、“小周”或对照用户隔离测试。
- 一个示例用户被写入至少三段独立会话，每段至少包含 user/assistant 两条消息。
- 页面能检索个人偏好和被更新的见面计划，并展示来源证据。
- DeepSeek/OpenAI 检索增强入口、通用连接路由和临时凭据保护保持可用。
- 桌面和移动端无横向溢出，无控制台错误或失败请求。

## 实施步骤

1. 更新 `tests/test_demo.py`，先锁定新的单用户 DOM、折叠设置和旧身份切换元素已移除，确认测试先失败。
2. 重写 `src/aml_memory/demo.html`：使用暖白对话布局、单用户多会话脚本、自由输入、建议问题和证据卡。
3. 保留通用检索连接逻辑和 `sessionStorage` 安全边界，删除只为多用户对照体验存在的状态与事件处理。
4. 更新 `README.md` 的演示说明，使操作步骤与新页面一致。
5. 运行 Ruff、mypy、pytest、compileall 和离线记忆挑战。
6. 启动隔离数据库的预览服务，使用真实浏览器验证写入请求、检索结果、响应式布局、console/API 错误，并截图执行视觉复核。

## 回归风险

- 全量重写前端可能误删模型连接的兼容头；通过字符串测试和浏览器请求验证保护。
- 预置会话按顺序写入，如果中途失败，页面必须保留已成功内容并允许重试。
- 日期文本是演示记忆而非真实日历计算，检索以文本与状态链排序为准。
- 页面状态只在当前运行命名空间内重置，不执行破坏性删除。
