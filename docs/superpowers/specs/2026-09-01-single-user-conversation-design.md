# 单用户多轮记忆体验设计

## 目标

把现有的“功能控制台”演示改成一次自然的个人记忆体验：用户不需要理解 `user_id`、隔离测试或检索术语，只要和同一个助手进行几段对话，再提问，就能直观看见它记住了偏好、事件以及事件的后续变更。

## 体验原则

- 页面只出现一个用户，不再提供主用户/对照用户切换。
- 用真实的多轮消息写入记忆，每段会话同时包含用户消息和助手回应。
- 用时间分段表现“过了一段时间又聊到同一件事”，突出跨会话记忆。
- 检索结果必须展示证据和时间，让用户看懂答案从哪里来；新计划应排在旧计划前面，旧计划仍保留为历史。
- API 和模型设置属于高级能力，默认折叠，不能抢占主要体验。
- 本地模式无需 Key；DeepSeek/OpenAI Key 只保存在当前标签页的 `sessionStorage`，且仅在检索时发送问题文本。

## 页面结构

### 顶栏

紧凑展示产品名、简短说明和服务状态。取消占据首屏的大型宣传区。

### 主区域：对话

左侧是同一个人与记忆助手的时间线，包含三段预置会话：

1. 咖啡偏好：用户说明只喝燕麦奶拿铁。
2. 初始计划：下周三下午三点和林老师在西湖边见面，并要带蓝色项目本。
3. 计划变更：见面改到周四上午十点，地点不变。

“载入示例对话”会依次调用 Add API。每次请求写入一段独立 session，且每段包含 user/assistant 两条消息。用户还可以在底部输入自己的新一轮对话。

### 右侧：记忆回想

提供两个建议问题和一个自由搜索框：

- “我和林老师什么时候见？”应优先看到周四上午十点，同时保留原计划作为历史证据。
- “我喝咖啡有什么习惯？”应召回燕麦奶偏好。

结果卡展示匹配内容、来源会话、角色、时间和分数，但不把内部算法术语放在主视觉上。

### 检索设置

使用折叠面板承载本地、DeepSeek 和 OpenAI 配置。连接、断开、模型与 Base URL 能力继续保留，名称改为“检索增强”，避免让用户误以为模型接管了记忆写入。

## 视觉方向

采用 Claude 式的安静、暖色、内容优先气质，但不复制商标或具体页面：

- 暖白背景、纸张白卡片、炭灰文字、陶土橙强调色。
- 细边框、轻阴影、较大留白；不使用霓虹渐变和大面积深色仪表盘。
- 系统字体，不引入网络字体或新依赖。
- 动效只用于状态切换，持续 150–220ms，并尊重 `prefers-reduced-motion`。
- 所有可操作目标至少 44px；移动端单列，无横向溢出。

## 状态与错误

- 未载入示例时，对话区给出明确空状态。
- 写入时逐段显示进度并禁用重复操作。
- 搜索前没有结果卡；搜索后区分命中、无结果和错误。
- 模型增强连接失败时保留本地检索能力，并给出可读错误，不阻断主要体验。
- “重新开始”只生成新的演示命名空间并清空当前页面状态，不删除数据库中的其他内容。

## 非目标

- 不在本次增加新后端依赖或改变公开评测 API 合约。
- 不让 DeepSeek 负责回答、总结或写入；它仍只做搜索问题扩展。
- 不在演示中继续讲多用户隔离，这项底层能力保留但不占据当前产品叙事。
